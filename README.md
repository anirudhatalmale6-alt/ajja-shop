# AJJA — Ankauf & Sofort-Auszahlung

WordPress plugin powering ajja.ch: a Swiss "instant cash for valuables" site.
Customers submit photos/video + description; the owner reviews and makes an offer;
14-day goodwill return guarantee (Rückgabe-Garantie aus Gutwill).

Dark blue + gold theme. Self-contained single-file plugin (custom routing, no block theme dependency).

## Features
- Custom front-end pages: home, /einreichen, /danke, /faq, /kontakt, /impressum, /agb, /datenschutz
- Submission form with photo (up to 3) + video upload → media library + `wp_ajja_submissions`
- Admin: Einreichungen (review + set offer price/status), Newsletter (import/send), Inhalte (editable texts)
- Newsletter + contact via wp_mail
